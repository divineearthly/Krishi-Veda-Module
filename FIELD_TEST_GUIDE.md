# 🌾 Krishi-Veda Field Test Guide

## Test Location: Silchar, Cachar, Assam
## Target: 10 farmers, 3 villages

### Phase 1: Baseline (Day 1)
- [ ] Install app on farmer phones
- [ ] Collect baseline soil data (pH, moisture, temp)
- [ ] Document current farming practices
- [ ] Record expected crop yields

### Phase 2: Usage (Days 2-14)
- [ ] Farmers ask 3 questions daily via app
- [ ] Log all queries and responses
- [ ] Track weather vs actual conditions
- [ ] Monitor Vedic wellness scores

### Phase 3: Validation (Day 15)
- [ ] Compare advice with SAU (Assam Agricultural University) recommendations
- [ ] Farmer satisfaction survey (1-5 scale)
- [ ] Measure time saved vs traditional extension services
- [ ] Document adoption barriers

### Success Metrics
- [ ] 80% advice rated "helpful" by farmers
- [ ] 90% uptime (offline-first design)
- [ ] <5 second response time
- [ ] 3+ languages used by farmers

### Feedback Questions
1. Was the advice understandable? (1-5)
2. Was the advice actionable? (1-5)
3. Did you follow the advice? (Yes/No)
4. Would you recommend to other farmers? (Yes/No)
5. What features are missing?
